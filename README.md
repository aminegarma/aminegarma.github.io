# Mohamed Amine Garma — Portfolio

Static personal portfolio. Open index.html locally or serve this directory as the web root. No installation or build is needed.

## Edit the content

- Project names, descriptions and technologies: projects.js
- About, experience, certificates and links: index.html
- Layout and colours: style.css
- CVs, photo and credential viewing copies: assets/

## Publish with GitHub Pages

1. Create a repository under your GitHub account. For a main personal site, name it aminegarma.github.io if available. For a project site, choose a name such as portfolio.
2. Upload the contents of this folder to the repository root, including index.html, style.css, app.js, projects.js, .nojekyll and assets/. Upload files, not this ZIP itself.
3. In repository Settings → Pages, choose Deploy from a branch → main → /(root), then Save.
4. GitHub displays the website address when deployment succeeds. The address is not live until that step completes.

Before public hosting, review all personal documents. This package contains your photo, English/French CVs, participation/membership certificates, and a BAC viewing copy with birth details, identifying numbers and verification code removed. It does not include original BAC scans, internship attestations, private project source code or medical data.

The layout and relative asset links support both an account site and a project site. A PDF viewer is not needed to run the website; diploma and CV links open separately in the browser.
